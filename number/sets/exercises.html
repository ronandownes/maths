Exercise 1 · Union and intersection

Active Maths 1 · Exercise 1.4 · pages 7–8

Classroom examples · even

Homework · odd

1, 3, 5, 7

Active Maths 1, Exercise 1.4, pp. 7–8. Show working and label each set clearly.

Extra classroom practice

A = {1, 2, 3, 6}, B = {2, 4, 6}. Find A ∪ B and A ∩ B.

Reveal solution

A ∪ B = {1, 2, 3, 4, 6}; A ∩ B = {2, 6}.

Homework · odd

Extra classroom practice

U = {1, 2, 3, 4, 5, 6, 7}, A = {2, 4, 6}. Find A′.

Reveal solution

A′ = U ∖ A = {1, 3, 5, 7}.

Exercise 3 · Set difference

Active Maths 1 · Exercise 1.6 · pages 12–13

Classroom examples · even

2, 4, 6, 8

“A without B” means A ∖ B. Check whether changing the order changes the answer.

Homework · odd

1, 3, 5, 7

Active Maths 1, Exercise 1.6, pp. 12–13.

Extra classroom practice

A = {1, 3, 4, 6}, B = {3, 5, 6}. Find A ∖ B and B ∖ A.

Reveal solution

A ∖ B = {1, 4}; B ∖ A = {5}. The order matters.

Exercise 4 · Counting with sets

Active Maths 1 · Exercise 1.7 · pages 14–16

Classroom examples · even

2, 4, 6, 8, 10

Fill the intersection first, then the two “only” regions and finally the outside.

Homework · odd

1, 3, 5, 7, 9

Active Maths 1, Exercise 1.7, pp. 14–16.

Extra classroom practice

In a group of 30, 17 study French, 14 study German and 6 study both. How many study neither?

Reveal solution

At least one = 17 + 14 − 6 = 25, so neither = 30 − 25 = 5.

Problem Solving

Choose the type of problem before attempting the calculation.

1 · Translate the language

“Or” means union (∪), including both. “And” means intersection (∩). “Not A” means complement A′, using U. “A but not B” means difference A ∖ B.

2 · Venn diagrams

Put known shared elements into the intersection. Work out each remaining region without counting an element twice.

Explore two sets

3 · Counting and cardinality

Use #(A ∪ B) = #A + #B − #(A ∩ B). If a total is given, subtract the union from the total to find neither.
