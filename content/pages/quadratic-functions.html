GraphsRootsVertexSymmetry

A quadratic function can be written f(x) = ax² + bx + c, where a ≠ 0. Its graph is a parabola.

1. Worked example

Consider f(x) = x² − 4x + 3.

Find the roots

f(x) = (x − 1)(x − 3)

The graph crosses the x-axis at x = 1 and x = 3.

Find the turning point

Complete the square:

f(x) = (x − 2)² − 1

Hence the turning point is (2, −1), a minimum. The axis of symmetry is x = 2.

2. Interpret the coefficient

If a is positive, the parabola opens upwards and its vertex is a minimum. If a is negative, it opens downwards and its vertex is a maximum.

3. Practice

For g(x) = x² − 6x + 8:

  1. Factorise g(x) and find its roots.
  2. Complete the square.
  3. Find the turning point and axis of symmetry.
  4. State whether the vertex is a maximum or minimum.
Reveal solutions
  1. (x − 2)(x − 4); roots 2 and 4.
  2. (x − 3)² − 1.
  3. Vertex (3, −1); axis x = 3.
  4. Minimum, since the coefficient of x² is positive.
