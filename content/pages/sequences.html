1. Arithmetic sequences

Worked example

3, 8, 13, 18, 23, …

Terms38131823
First differences+5    +5    +5    +5

The first difference is a constant 5, so the sequence is arithmetic.

Tn = a + (n − 1)d = 3 + 5(n − 1) = 5n − 2

Check: T1 = 3 and T2 = 8.

2. Working backwards to term zero

For 3, 8, 13, …, subtract the first difference 5 to go back from the first term to T0 = −2. The form Tn = 5n − 2 then follows immediately.

3. Quadratic sequences

Worked example

3, 8, 15, 24, 35, …

Terms38152435
First differences5    7    9    11
Second differences2    2    2

The second difference is a constant 2. The sequence is quadratic.

Assume Tn = an² + bn + c. Then 2a = 2, so a = 1.

Subtract n² from each original term, giving 2, 4, 6, 8, 10, …. This remaining sequence has nth term 2n.

Tn = n² + 2n

Verify: T3 = 9 + 6 = 15.

Classification: A constant first difference indicates an arithmetic sequence. A constant non-zero second difference indicates a quadratic sequence.

4. Practice

  1. Classify 7, 15, 23, 31, 39 and find its nth term.
  2. Classify 12, 9, 6, 3, 0 and find its nth term.
  3. Find the first and second differences of 4, 11, 22, 37, 56, and find a formula for Tn.
Reveal solutions
  1. Arithmetic; common difference 8; Tn = 8n − 1.
  2. Arithmetic; common difference −3; Tn = 15 − 3n.
  3. Differences 7, 11, 15, 19; second differences 4, 4, 4. Thus a = 2. Subtract 2n²: 2, 3, 4, 5, 6, leaving n + 1. Tn = 2n² + n + 1.
