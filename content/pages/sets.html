A set is a well-defined collection of distinct elements.

Introduction

A = {2, 4, 6} is a set. Its elements are 2, 4 and 6.

2 ∈ A means 2 belongs to A. 3 ∉ A means 3 does not belong to A. #A = 3.

Think

Is “the three nicest numbers” a well-defined set? What about “the even numbers between 1 and 7”?

Check

Only the second description is unambiguous. Its elements are {2, 4, 6}.

Subsets

A ⊂ B means every element of A belongs to B, using the Formulae and Tables convention.

For A = {2, 4} and B = {2, 4, 6}, we have A ⊂ B.

2 ∈ B says that 2 is an element. {2} ⊂ B says a set is a subset.

The empty set ∅ is a subset of every set, including itself.

Rule Notation

Instead of listing every element, describe what each element must satisfy.

A = {x ∈ ℕ : x is even and x < 10}

Read: “A is the set of natural numbers x such that x is even and less than 10.”

In list notation, A = {2, 4, 6, 8}.

The colon means “such that”. Since the log tables start ℕ at 1, zero is not included here. However, zero is a multiple of 2.

Union

A ∪ B means elements in A or B or both.

Let A = {1, 2, 3} and B = {3, 4, 5}.

A ∪ B = {1, 2, 3, 4, 5}

List the shared element 3 only once.

Try: {2, 4, 6} ∪ {4, 8}
{2, 4, 6, 8}.

Intersection

A ∩ B means elements in both A and B.

For A = {1, 2, 3} and B = {3, 4, 5}:

A ∩ B = {3}

If there are no common elements, the intersection is the empty set ∅.

Try: {2, 4, 6} ∩ {4, 8}
{4}.

Cardinality

Cardinality is the number of distinct elements. Write #A for the number of elements in A.

Suppose 18 students play football, 13 play music and 5 do both. How many play at least one?

Count the overlap only once
#(A ∪ B) = #A + #B − #(A ∩ B)

18 + 13 − 5 = 26. The five students in both sets were counted twice when we added 18 and 13.

Try

In a class, 17 study French, 14 study German and 6 study both. How many study at least one language?

Answer

17 + 14 − 6 = 25.

The universal set U contains every element under consideration.

For example, let U = {1, 2, 3, 4, 5, 6} and A = {2, 4, 6}.

Complement

Aᶜ is everything in U but not A.

With U = {1, 2, 3, 4, 5, 6} and A = {2, 4, 6}:

Set Difference

A \ B contains elements in A but not B.

If A = {1, 2, 3} and B = {3, 4}, then A \ B = {1, 2} but B \ A = {4}.

Therefore, changing the order can change the answer.

Disjoint Sets

Disjoint sets have no common elements, so A ∩ B = ∅.

In a standard pack of cards, the spades and hearts form disjoint sets. They are not complements because clubs and diamonds are outside both.

The red and black cards are disjoint and complementary, if the universal set is the whole pack.

Test the distinction

Let U = {1, 2, 3, 4, 5}, A = {1, 2} and B = {4, 5}. Are A and B disjoint? Are they complements?

Answer

They are disjoint, since A ∩ B = ∅, but not complements: 3 belongs to neither set.

Problem Solving

Start with two sets. Put the shared elements into the overlap first, then work out the elements in each outer region.

Two-set problem

Of 32 students, 19 like football, 16 like music, and 7 like both. Find the number who like neither.

Solution

At least one: 19 + 16 − 7 = 28. Neither: 32 − 28 = 4.

Three-set extension

Of 40 students, 20 are in A, 18 in B and 15 in C. Exactly 5 belong to A and B only, 4 to A and C only, 3 to B and C only, and 2 to all three. Find the number in the union.

Solution

A only = 20 − 5 − 4 − 2 = 9. B only = 18 − 5 − 3 − 2 = 8. C only = 15 − 4 − 3 − 2 = 6. Union = 9 + 8 + 6 + 5 + 4 + 3 + 2 = 37.

Reasoning

Strong mathematical thinking means making an argument that works in every case, or finding one counterexample that proves a claim is false.

Reasoning 1

If A ⊂ B and B ⊂ A, must A = B?

Reveal a proof

Yes. Choose any element x of A; because A ⊂ B, x ∈ B. Conversely, choose any y ∈ B; because B ⊂ A, y ∈ A. Thus both sets have precisely the same elements.

Reasoning 2

If #A = #B, must A = B?

Reveal a counterexample

No. A = {1, 2} and B = {3, 4} each have two elements but A ≠ B.

Reasoning 3

Is A \ B always equal to B \ A?

Reveal a counterexample

No. With A = {1} and B = {2}, A \ B = {1}, whereas B \ A = {2}. Set difference is not generally commutative.

Reasoning 4

Can A ⊂ B and A ∩ B = ∅ both be true?

Reveal the subtle case

Yes, but only if A = ∅. Since A ⊂ B, the intersection is A. For it to be empty, A itself must be empty.
