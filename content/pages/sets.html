A set is a well-defined collection of distinct objects. We write the elements between curly brackets, for example A = {1, 2, 3}.

1. Membership

2 ∈ A   and   5 ∉ A

The symbol ∈ means “is an element of”. The symbol ∉ means “is not an element of”. The order of the elements does not matter; repeating an element does not create a new element.

2. Subsets

Recognise a subset

Let A = {1, 2} and B = {1, 2, 3, 4, 5, 6}.

A ⊆ B

Every element of A is also an element of B. In fact, A is a proper subset of B, because B contains elements not in A: A ⊊ B.

Important distinction: 2 ∈ B is a membership statement about an element. {2} ⊆ B is a subset statement about a set.

3. Empty set and equality

The empty set ∅ contains no elements. It is a subset of every set. Two sets are equal if they contain exactly the same elements, regardless of order.

4. Worked examples

Example A

Is {3, 5} ⊆ {1, 3, 5, 7}?

Yes: both 3 and 5 occur in the larger set.

Example B

Is {2, 4} ⊆ {2, 3, 5}?

No: 4 is missing.

5. Classroom practice

Let U = {1, 2, 3, 4, 5, 6}, P = {2, 4, 6} and Q = {1, 2}.

  1. Write a membership statement for the number 4 and the set P.
  2. Is Q a subset of P? Justify your answer.
  3. Give a proper subset of P containing exactly two elements.
  4. Is the empty set a subset of Q?
Reveal solutions
  1. 4 ∈ P.
  2. No. Although 2 is in P, 1 is not.
  3. For example, {2, 4}, {2, 6}, or {4, 6}.
  4. Yes, ∅ ⊆ Q.

Teaching sequence: Start with membership, introduce subsets using concrete examples, then distinguish an element from a singleton set before introducing Venn diagrams.
