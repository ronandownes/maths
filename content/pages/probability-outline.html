13.1 Introducing Probability

Probability measures how likely an event is. It ranges from 0 (impossible) to 1 (certain).

0 ≤ P(A) ≤ 1

For a fair coin, P(heads) = ½.

13.2 Relative Frequency (Experimental Probability)

Estimate probability by repeating a random experiment.

Relative frequency = successes ÷ trials

If heads occurs 19 times in 50 tosses, the relative frequency is 19/50 = 0.38.

13.3 Theoretical Probability

When all outcomes are equally likely:

P(A) = favourable outcomes ÷ total outcomes

For a fair die, P(even number) = 3/6 = ½.

13.4 Set Theory and Probability

Events are sets of outcomes. Let A = {2, 4, 6} and B = {4, 5, 6} for a fair die.

A ∩ B = {4, 6}; A ∪ B = {2, 4, 5, 6}.

13.5 Sample Spaces for Successive Events

List every possible ordered result of a sequence of events.

Two coin tosses: HH, HT, TH, TT. There are four equally likely outcomes, so P(exactly one head) = 2/4 = ½.

13.6 AND/OR: Multiple Events

AND means both events occur. OR means at least one occurs.

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Subtract the overlap once to avoid double counting.

13.7 Bernoulli Trials LC

A Bernoulli trial has exactly two outcomes: success and failure. Repeated independent trials with constant success probability p form a binomial model.

P(X = k) = C(n, k) pᵏ(1 − p)ⁿ⁻ᵏ

For three fair coin tosses, P(exactly two heads) = 3/8.

13.8 Expected Value LC

Expected value is the long-run mean outcome of a random variable.

E(X) = Σ x P(X = x)

A fair die has expected value (1 + 2 + 3 + 4 + 5 + 6)/6 = 3.5.
