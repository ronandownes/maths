NUMBER · SETS APP 5

Four familiar number sets

The log tables list the natural numbers, integers, rational numbers and real numbers. First look at how they fit together; then practise choosing the smallest set that contains a number.

Read-only examples · no choices yet

Each set contains the one before it

Natural numbers · ℕ

ℕ = {1, 2, 3, …}

In the log tables, the natural numbers start at 1: the first object, the second, the third and so on.

Integers · ℤ

ℤ = {…, −2, −1, 0, 1, 2, …}
= {0, ±1, ±2, …}

Each ±n means the pair −n and +n. Zero appears once.

Rational numbers · ℚ

ℚ = {p/q : p, q ∈ ℤ, q ≠ 0}

Examples include ½, −¾ and 5 = 5/1.

Real numbers · ℝ

ℝ = all points on the number line

Real numbers include rational numbers and numbers such as √2 and π.

Why does this book leave zero out of ℕ? When we count objects, we say first, second, third… If a chicken coop is empty, we say there are zero chickens. Zero tells the size of the empty collection; it is not a chicken we counted.

So, following the log tables, ℕ = {1, 2, 3, …} and 0 ∉ ℕ. Zero is still an integer: 0 ∈ ℤ. Some books use a different convention; in this class we follow the tables.

Irrational numbers · ℝ \ ℚ

ℝ \ ℚ

Numbers such as √2 and π are real but are not fractions of integers. This set is introduced alongside the five named in the tables.

Complex numbers · ℂ

ℂ = {a + bi : a, b ∈ ℝ, i² = −1}

Page 23 includes ℂ. All real numbers are complex (take b = 0). Numbers such as 2 + 3i are not real.

Reference: Formulae and Tables, printed p. 23. The nested diagram above shows the four familiar sets; the two extra categories are explained separately.

Extra investigation 1

Why is 0.272727… rational?

Show answer

0.272727… = 27/99 = 3/11.

Extra investigation 2

Compare √9 with √−9. Which is real?

Show answer

√9 = 3 is natural; √−9 = 3i is complex but not real.
