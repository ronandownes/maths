Choose a Sets app

Begin with one circle. Move the elements. Then read set notation, explore rules, and investigate overlapping sets.

Learn Sets in this order
  1. Move elements inside one circle. Discover that order does not matter.
  2. List elements and read set notation.
  3. Use a rule to build a set and translate it into a list.
  4. Meet the natural numbers, integers, rational numbers and real numbers.
  5. Explore two sets without a universal-set rectangle.
  6. Sort numbered elements, infer missing labels and discover common multiples and the LCM.
  7. Introduce the universal set and complement.
