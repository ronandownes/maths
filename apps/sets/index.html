NUMBER · SETS

Choose a Sets app

Each app has one clear job and connects to a section in the book. Begin with lists and notation, build a set from a rule, then explore two-set Venn diagrams. Meet the universal set and complement as a separate idea.

A suggested learning path
  1. List elements and read set notation.
  2. Use a rule to build a set and translate it into a list.
  3. Explore two sets without a universal-set rectangle.
  4. Introduce the universal set and complement.

Venn operations and problem solving

Explore both, only A, only B, intersection, union and difference without a universal-set rectangle. The app uses digital shading; on paper, use a few clear hatch strokes. Practise, play a region game, take a quiz or test, then unlock three sets.
