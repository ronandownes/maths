Language

One set. One circle.

A set is a collection of distinct elements. Rearranging its elements does not change the set.

A
A = {spring, summer, autumn, winter}

#A = 4

Drag an element, or use the arrow keys to move it.

The elements can be in any order. All remain inside the set.

Mathematical words

Set
A well-defined collection of distinct objects.
Element
One object belonging to a set.
Cardinality
The number of distinct elements in a set. Written here as #A.
Multiple
A multiple of 2 is a number of the form 2n, where n is an integer. Zero is a multiple of 2 because 2 × 0 = 0.
