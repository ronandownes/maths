Number Venn Laboratory

Which numbers belong in each set? Make decisions, test your reasoning, discover hidden set rules and investigate why common multiples lead to the least common multiple (LCM).

⚙ Set up your own diagram — change the rules and the highest number

Use positive whole numbers from 1 to your chosen maximum. Change either rule to create a new diagram.

For projector visibility, 1–30 is a useful starting range. Larger ranges make the diagram taller; all numbers remain individually selectable. Zero is excluded from these activities.
