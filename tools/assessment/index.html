Use with Google Classroom

The simple, free option is to attach a link to an activity as an assignment or class material. This does not automatically copy scores into Google Classroom. Use your school's approved Classroom account and obtain approval before collecting identifiable pupil results.

Open Google Classroom

  1. Open your school's Google Classroom course.
  2. Go to Classwork → Create → Assignment (or Material for ungraded practice).
  3. Add the copied URL using Link and write your instructions.
  4. Review the assigned class and pupils, then publish from your own school account.

Privacy: This page uses no analytics or database, and never asks students to enter names. Do not upload identifiable pupil marks or rosters to a personal GitHub repository or third-party service without school authorisation.
